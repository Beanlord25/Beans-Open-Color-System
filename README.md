# Beans-Open-Color-System
Simple color class for python.

I built this for projects that need to use color without importing external modules.
It uses the standard ANSI color codes. Feel free to add more, its very basic to begin with.
I expect to add more colors and style options in the future.

For a place to get the codes I used, check out this gist by fnky.

https://gist.github.com/fnky/458719343aabd01cfb17a3a4f7296797
